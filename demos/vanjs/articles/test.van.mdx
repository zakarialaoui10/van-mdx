# Van-MDX: MDX for VanJS

[VanJS](https://vanjs.org/) is a tiny framework for building reactive interfaces with JavaScript and the DOM.

**Van-MDX** brings the flexibility of MDX to VanJS, allowing you to combine Markdown, HTML, JavaScript, JSX-style components, and VanJS in the same document.

## What is Van-MDX?

Van-MDX lets you write normal Markdown while embedding interactive VanJS components when needed:

```md
# Hello {name}

This is a Markdown article.

<Counter />
```

This makes it useful for documentation, tutorials, blogs, and interactive articles.

---

# Features

### Simple Integration

Write Markdown normally and add VanJS components where needed.

```md
# My Article

This is normal Markdown.

<Button>Click me</Button>
```

### Extensible & Reusable

Create components with VanJS and reuse them throughout your documents:

```jsx
<Counter initial={10} />
```

Components can receive props and be used multiple times with different data.

```jsx
<UserCard name="Alice" role="Designer" />

<UserCard name="Bob" role="Developer" />
```

### Markdown & HTML

Standard Markdown and HTML are supported:

```md
# Heading

**Bold**, *italic*, and lists are supported.
```

```html
<div class="notice">
  <strong>Note:</strong>
  This is HTML.
</div>
```

### Frontmatter

Define document metadata using YAML frontmatter:

```yaml
---
title: "Getting Started"
description: "Build interactive content with VanJS"
author: "Zakaria Elalaoui"
---
```

### JSX Syntax

Van-MDX supports JSX-style component syntax while using VanJS for the resulting UI:

```jsx
<Card title="Hello VanJS">
  <p>Interactive content.</p>
</Card>
```

### Props & Attributes

Pass dynamic values to components:

```jsx
<Button
  type="primary"
  disabled={false}
>
  Continue
</Button>
```

Props can also be used to customize reusable components.

### ESM

Import components and utilities directly into your document:

```js
import Counter from "../components/counter.js";
```

Then use them:

```jsx
<Counter />
```

For example, a reusable VanJS component can live in a normal JavaScript module:

```js
import van from "vanjs-core";

const { button } = van.tags;

export default function Counter() {
  const count = van.state(0);

  return button(
    () => `Count: ${count.val}`,
    {
      onclick: () => count.val++
    }
  );
}
```

### Expressions

JavaScript expressions can be embedded using `{}`:

```md
Hello {name}
```

Expressions can also contain arbitrary JavaScript that evaluates to a renderable value:

```jsx
Hello {(() => {
  const names = ["world", "everyone"];
  return names[Math.floor(Math.random() * names.length)];
})()}
```

### Internal Scripts

JavaScript can be used for logic that isn't rendered directly:

```js
const name = "VanJS";
const version = "1.0";
```

These values can then be used by expressions and components.

### Interleaving

Markdown, HTML, JSX, and expressions can be combined:

```jsx
<p>
  ***Hello {name}***
</p>
```

This allows content to move naturally between Markdown and interactive UI.

# Vite Integration

Van-MDX integrates with Vite through `vite-plugin-van-mdx`.

```js
import { defineConfig } from "vite";
import VanMdx from "vite-plugin-van-mdx";

export default defineConfig({
  plugins: [
    VanMdx()
  ]
});
```

## File Marker

A custom marker can be configured for Van-MDX files:

```js
VanMdx({
  marker: ".van"
})
```

For example:

```text
article.van.mdx
```

## Include

Limit processing to specific files:

```js
VanMdx({
  include: ["**/articles/*"]
})
```

This is useful when only a specific directory contains your Van-MDX articles.

# Syntax Highlighting

Syntax highlighting can be provided through an adapter:

```js
import syntaxHighlightAdapter
  from "@zikojs/mdx-highlightjs-adapter";

VanMdx({
  syntaxHighlightAdapter
});
```

Using an adapter keeps syntax highlighting separate from the Van-MDX core.

---

# Plugins

Van-MDX can be extended through plugins:

```js
VanMdx({
  plugins: [
    // MindElixir()
  ]
});
```

Plugins can provide features such as diagrams, mind maps, charts, or other specialized content.

---

# Complete Configuration

A complete setup can look like this:

```js
import { defineConfig } from "vite";

import VanMdx from "vite-plugin-van-mdx";
import syntaxHighlightAdapter
  from "@zikojs/mdx-highlightjs-adapter";

export default defineConfig({
  plugins: [
    VanMdx({
      syntaxHighlightAdapter,
      marker: ".van",
      include: ["**/articles/*"],
      plugins: [
        // MindElixir()
      ]
    })
  ]
});
```

| Option                   | Purpose                         |
| ------------------------ | ------------------------------- |
| `syntaxHighlightAdapter` | Adds syntax highlighting        |
| `marker`                 | Defines the Van-MDX file marker |
| `include`                | Selects files to process        |
| `plugins`                | Adds extensions                 |

# Architecture

Van-MDX keeps the core focused while allowing functionality to be added through adapters and plugins:

```text
                  Vite
                    │
                    ▼
              ┌───────────┐
              │  Van-MDX  │
              └─────┬─────┘
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
    Markdown      Plugins    Adapters
        │           │           │
        ▼           ▼           ▼
      HTML       Components   Highlighting
        │        Diagrams
        │        Charts
        ▼
      VanJS
```

The result is a lightweight authoring environment where **content and interactive UI can live together**.

# Conclusion

Van-MDX combines the simplicity of Markdown with the flexibility of VanJS.

It provides:

* Markdown and HTML
* JSX-style components
* Props and attributes
* JavaScript expressions
* Internal scripts
* ESM imports
* YAML frontmatter
* Syntax-highlighting adapters
* Extensible plugins
* Vite integration

The idea is simple:

> **Write content with Markdown, extend it with JavaScript, and make it interactive with VanJS.**
